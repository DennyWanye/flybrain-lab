# 怎样查看和测试本轮结果

打开 http://127.0.0.1:8765/tellosim ，等页面显示本轮 C1 结果。

1. 点击「C1 模型 22」看成功样例，再点11看同场景的超时失败。三个快捷入口都固定使用第一个封存场景，11超时、22/33成功，没有挑掉失败样例；三者使用同一份冻结 MaleCNS 连接图。
2. 点击「暂停」，拖动「回放时间」，再点击「播放」。画面、命令、观测和神经活动跟随记录的时间点；这是已录制的模型行为。
3. 点击「平移模式」，在画布里左键拖动；点击「切回旋转」恢复旋转操作。「重置视角」返回初始视角，滚轮缩放。画布移动不会修改无人机状态。
4. 分别点「C1 对照 · 训练前」与「C1 对照 · 训练后」。两者都是 c1-val-000，可暂停后拖到12秒对照。训练前是旧 C0 权重，两次在这个场景都成功；用下方多场景统计判断整体能力，不凭单个片段判断训练收益。
5. 「训练观察」里选择 c1-s11-ppo，再切换环境0—3。结束后显示「最后快照」，不是一段可拖动的训练录像；本阶段128个动作属于本轮1536个动作的一部分。新的训练启动后，这里可观察实时场景，暂停页面只暂停显示。

右侧「策略与奖励」是记录的9动作概率、价值和奖励；起飞阶段还没做模型决策，会明确显示任务管理器阶段。下方「神经活动」只显示记录下来的神经元采样，不代表整个大脑的解剖位置。

想亲手试SDK操作，可以点击「新建手动沙盒」，先进入SDK，再起飞、平移、停止、降落，完成后点「结束并保存」。它有独立运行编号；手动按钮不控制训练或验收运行。手动成功也不会改变模型成绩。

查看正式成绩时，重点看三组 C1 封存结果和 C0 保持门槛。具体失败场景见 failed-cases.json，完整验收范围见 TEST_MATRIX.md；本轮没有实机控制。
