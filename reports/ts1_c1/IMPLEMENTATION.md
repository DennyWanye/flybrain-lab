# C1 可靠性与训练观察

## 独立环境

每个 AgentLane 持有独立的 CPU Torch Generator。策略多项式采样只推进本环境的状态，其他环境完成、reset、调用顺序或全局 Torch RNG 不改变该环境的后续动作序列。精确训练快照升级为 v3，保存各环境策略 RNG，旧 v2 不静默迁移。完整真实 MaleCNS 图的边界恢复已对照模型、优化器、脑、环境随机数、物理和传感器状态。

## C1

固定初始位置分布与 C0 相同，初始 yaw 均匀分布于 [-pi,pi]。初始条件在物理 reset 时设置，tick 0 已记录实际四元数；随后旋转由物理力矩完成。C1 保留 9 个 logits，允许 STOP/前后左右/顺逆时针30度，仍不开放升降课程。成功条件仍是目标处稳定保持2秒；不要求最终机头朝向，因此达标也不能解释为已学会指定终点朝向。

## 观察

每次训练尝试有独立 epoch，四环境各有独立 run_id；跨 episode 的身份、目标和轨迹一起替换。最新帧队列只有一个槽位，慢读者只能漏看帧，不能向训练队列积压请求。浏览器从文件快照读取；手动命令端点仅允许独立沙盒。观察对象不进入训练快照，也不改变策略输入或奖励。

观察开启仍有采样和序列化的计算成本；“不背压”不等于零开销。压力报告明确区分五个 HTTP 消费者和五个浏览器渲染实例。

## 预算与停止

本轮固定每种子 384 示范 + 1024 DAgger + 128 PPO = 1536 动作，最多1800秒。每4个训练 episode 有1个 C0 保持练习。PPO 支持精确边界恢复；监督/DAgger 采集阶段保存阶段权重和数据来源，不冒充任意中途精确恢复。SIGINT/SIGTERM 丢弃尚未提交 rollout，使用最后原子快照；实际执行与已提交计数分开。墙钟预算恢复时计入上次运行消耗，不靠重复启动重置上限。

所有图权重冻结，仅训练动作/价值读出。封存结果打开前同时锁定三个模型。C0 保持评估也用新场景；达标要求至少90%，且相对同场景初始权重下降不超过5个百分点。C2 与真机不属于本轮达标结论。

## 回放导出身份

底层VisualSession是单环境记录器，本地env_id为0；TrainingEnv的声明使用外层lane/case。新增view_export明确将完整记录的trajectory/operation/neural/transition身份统一到声明中的run/epoch/env/episode。导出前检查原始分块哈希，拒绝外来run或lane；非身份字段的规范化payload哈希前后相等，数值、动作与神经活动不变。每个分块的原始/导出哈希都保存于manifest的identity_export和VIEW_EXPORT_AUDIT.json；Golden与历史回放不修改。

本次正式评估启动时尚未附加这一导出步骤，故完成后统一导出；数值评估源码保存在evaluation-source-before-export.py。后续evaluate_batch在记录关闭时自动执行同一导出步骤。神经/物理/恢复执行合同源文件没有因此变化，三个冻结checkpoint不改写。两项定向测试通过。

导出测试首次发现返回审计中的tuple经JSON落盘变为list，幂等返回值不一致；已统一为JSON原生list并通过两项复测。训练/PPO执行合同与冻结checkpoint哈希再次核对均未改变。
