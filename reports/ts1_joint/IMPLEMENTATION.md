# J1 连续联合任务

两个冻结读出共享 MaleCNS reservoir；phase manager 只按外部测量决定技能切换，不选择动作方向。导航使用原 C1 绝对朝向观测；转向使用 H1 目标角误差观测，并将到达点的测量 XY 作为原地转向锚点。全程原始目标位置不变。

到位稳定2秒且 SDK 命令已完成后切换；只重置对应神经 lane，保留物理积分状态、SDK目标及单调神经时钟，下一新物理采样预热。离开全局目标范围持续0.5秒后返回导航。总限时120秒，每阶段60秒。

终止成功要求：全局水平距离≤0.2米、高度误差≤0.1米、水平速度≤0.08米/秒、朝向误差≤16度、角速度≤0.08弧度/秒，并同时保持2秒。真实物理状态仅用于奖励与验收；切换和策略仅用模拟传感器观测。

评估：三个冻结种子，每个100验证+300封存；相同封存随机基线；100规则基线；每种子4个相反朝向指令对照和12个零神经特征消融。源权重、组合代码、用例在封存评估前锁定，禁止根据封存结果调参。每种子成功率≥90%、碰撞/越界≤1%、领先随机≥20个百分点，同时通过指令/时钟/状态连续性检查。

范围：空房间固定高度，模拟外部定位和工程刚体模型。没有新增训练，没有单一策略端到端联合学习，不代表实机可飞。历史独立 C1/H1 成绩保留但本轮不宣称重跑。
