# 后续硬件阶段验收清单 V1

本清单记录待做事项，不授权设备控制或真实飞行。设备型号与定位来源尚未获得确认。软件默认阈值为开发预算，不能当实机标定结论。

| 阶段 | 必要证据 | 当前状态 |
|---|---|---|
| 设备清单 | 无人机具体型号/固件/SDK；定位设备与软件；采集主机；安装方式；坐标和高度零点 | PENDING_INPUT |
| 定位坐标与单位 | 独立测量的 XYZ 标定点；正负三个方向；yaw 的零点/正方向；速度参考；地图变换残差 | NOT_RUN |
| 定位动态质量 | 位置/yaw/速度误差分布；遮挡/重定位跳变；采样与接收延迟分布；时间同步误差；丢帧和恢复数据 | NOT_RUN |
| 真实数据离线 Shadow | real_recording 的来源证据、完整原始数据；三阶段输入/神经/建议；错误与失败保留；未发送命令 | NOT_RUN |
| 标定方案 | 先固定试验次数、目标、接受范围和停止条件；根据设备规格与观测误差制定，不按试验结果降低门槛 | NOT_RUN |
| SDK 动作标定 | 20cm 平移、30deg 转向的方向、距离、延迟、完成判据；STOP 制动与重复 STOP；移动/转向对其他轴和高度影响 | NOT_RUN |
| C2W 控制差异核对 | 模拟执行器保持未操作轴的目标；实际 SDK 是否同等保持、漂移有多大；若不同需新版本适配和新验证 | NOT_RUN |
| 运行故障 | 接收中断、时钟跳变、定位丢失、unknown completion、电量与状态异常；真实保护行为需独立验证 | NOT_RUN |
| 硬件 Shadow | 有监督数据采集、真实端到端 10Hz 性能与积压检查；隔离建议和实际指令；不把建议当动作完成 | NOT_RUN |
| 受控飞行 | 前述项目通过；明确场地/人员/停止与接管方式；用户单独授权；预先冻结场景、模型与验收条件 | NOT_AUTHORIZED |

首个硬件依赖交付是“只读采集器 + 一份可追溯真实定位记录 + 标定结果”，而非飞行命令发送器。无人机若缺少独立室内 XYZ 来源，不能用模拟真值、纯高度或未校准积分补成已满足定位。

软件中所有 readiness 均保持硬件未验证和 REAL_FLIGHT_READY=false。定位误差、通信时间、机型响应尚无实测时，不能为实机编造数值通过标准。未来冻结实测方案时应为定位/控制误差分配原任务容差预算，必要时承认模型与硬件不兼容并建立新版本，而不是放宽既有模拟门槛。
