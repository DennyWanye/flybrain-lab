# 本轮发现与处理

1. 旧模型直接迁移到真实机身推力的物理环境，验证降到 93%、89%、85%。保留原权重与完整逐 case 结果；用新训练样本限额适配，不把脚本基线当模型成绩。
2. 初次 GPU 浮点恢复严格比较失败，少数膜电位差异约 5.96e-8..1.19e-7。打开确定性开关或仅切 COO 仍不稳定。采用版本化 FP64 累加后，独立 CPU 参考与三次恢复重复通过。失败文件 `perf-final-*`、`perf-deterministic-*`、`perf-coo-*`、`perf-release-*` 不属于有效交付恢复文件。
3. 浏览器视角复位残留 OrbitControls 平移阻尼。复位时先清除阻尼，再设置相机；实际拖动复测通过。
4. 评估证据脚本的 numpy.bool JSON 序列化，以及 deque 内数组比较曾报错。修复证据脚本；未将报错运行记为通过。首轮规则 100/100 已完成结果被保留复核，不重复冒充新评估。
5. 中间 COO 模型的开发评估因最终后端升级而中断，记录在 superseded-evaluation.json；只使用 final-* 的完整评估统计作验收。
