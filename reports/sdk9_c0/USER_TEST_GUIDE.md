# 醒来后怎样查看和测试

打开 http://127.0.0.1:8765/tellosim ，先看「SDK9 果蝇训练」里的三个种子成绩与 MODEL READY 状态。最终结论以 summary.json 为准。

## 看训练模型

1. 页面顶部点击「先看模型 11 · 点击播放」，会从头自动播放。旁边「对比模型 22」「对比模型 33」可对比同一正式测试场景。「再看失败样例」展示开发验证中的失败。也可以使用下方成绩表中的「模型 11 回放」「模型 22 回放」「模型 33 回放」。这三个读出各自独立训练，共用同一冻结果蝇连接组。
2. 点击播放，观察目标区、无人机位置、测量位置、动作概率、命令回执及神经活动。前约 5.9 秒是任务管理器起飞，不是模型动作。
3. 点击暂停并拖动时间条，或通过「跳到命令」直接查看某一步。暂停不会重新执行模型，只是在读保存的轨迹。
4. 左键旋转、滚轮缩放；勾选「平移模式」后拖动画布平移；「重置视角」恢复。改变镜头不改变任务结果。
5. 若有「失败样例」，也请查看：到达目标附近后还需要低速保持 2 秒。不能只看最后一帧的位置来判断成功。

## 手动检查模拟 SDK

点击「新建手动沙盒」，依次使用「进入 SDK」「起飞」「左移 20 cm」「保护停止」「降落」按钮；它们分别对应 command、takeoff、left 20、stop 和 land。它创建独立的手动运行，不会改写训练权重。完成后点击「结束并保存」。这些按钮只控制本地模拟器。

## 理解成绩

- 开发验证：100 个固定独立场景，用于发现问题。
- 封存验收：三个最终权重锁定后，分别执行相同 300 场景。每个模型单独达标，不从三个模型中挑一个代表全部。
- 固定部署采用 argmax，即选概率最高的合法动作。采样动作的诊断成绩另列，不能混为同一种控制模式。
- 成功条件：水平距离不超过 20 cm、水平速度不超过 8 cm/s、高度误差不超过 10 cm，连续保持 2 秒，任务时间不超过 60 秒。
- C0 只覆盖固定高度空房间中的前后左右控制。真实无人机、视觉感知、避障和高度/朝向变化还没有被这些成绩验证。
- 页面显示的神经活动是真实运行的模拟连接组活动，但连接组突触没有经过这轮训练；更新的是动作与价值读出。

## 服务重启

在现有 Ubuntu-24.04 WSL 项目中运行：

```bash
cd /home/denny/projects/flybrain_lab_4spark_v0_1
/home/denny/projects/flybrain-env/bin/python -m flyview serve --project-root . --host 127.0.0.1 --port 8765
```

训练权重与逐场景结果已保存，不依赖浏览器持续打开。若端口已有服务，不要再启动第二份。原始大图和 Python 虚拟环境保留在本机，交付 ZIP 不重复包含它们。
